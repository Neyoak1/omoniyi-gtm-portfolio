## Deploying with GitHub and Vercel
1. Replace the files in the GitHub repository connected to your Vercel project with these files.
2. Keep `index.html` at the repository root.
3. Commit the changes; Vercel should redeploy automatically.
4. Replace domain placeholders after buying and connecting the final domain.
5. Configure a form service before treating website submissions as direct delivery.

## Before launch
- Confirm the final domain and update canonical URL, sitemap, Open Graph metadata, and structured data.
- Verify links, contact details, and mobile layout.
- Label project concepts honestly until implemented and supported by real results.
